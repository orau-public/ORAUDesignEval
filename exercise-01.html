Exercise 1 - Form Layout

Instructions

  • Reproduce the wireframe linked below as an HTML form. Add your code directly in this file.
  • For this exercise, only design for desktop screen resolutions (i.e., the page doesn’t need to be responsive).
  • Use Bootstrap components and class names to style the form.
  • Use appropriate HTML attributes for inputs that expect a specific type of information (email, dates, etc.)
  • If you need to add any custom styles, place them in the <style> element in this file, or in assets/scss/_custom.scss.
